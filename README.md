# Tester l'atelier 2
1. Ouvrir le projet dans Vivado
2. Connecter et allumer le FPGA (Câble USB + HDMI)
4. Écrire le bitstream dans le FPGA
5. Ouvrir Vitis à partir de Vivado (Tools > Launch Vitis IDE)
6. Modifier le workspace pour le répertoire C:\Travail\s4-projet\vivado\ 
7. Build le projet (Projet > Build All)
8. Exécuter le projet (ou débugger le, il faut juste le forcer à continuer car il arrête automatiquement dans le cas d'un debug)
